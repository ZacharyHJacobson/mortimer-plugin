# Mortimer Calculator
This is a calculator that determines which of the tasks Mortimer offers is optimal for you to choose if you're chasing the Imbued Heart. It uses the same methodology as the simulator found here:
https://github.com/ZacharyHJacobson/MortimerSim

When using the plugin, it's assumed that you'll have Hydras and Venators blocked, but it will still function if you don't.  These are the two tasks increase the amount of hours to obtain a heart the most, so they're the most beneficial to block.  Only Araxytes (one of the best tasks) and Dark Beasts (usually skipped when no droprate buff is present anyways) are worth extending.

Go to Mortimer and the calculator will open.  Request a task from him and the fields should fill in, suggesting which task is best and what bracelet to use.  If this doesn't work (week one plugin jank), close the task UI and enter any missing or incorrect information.

If you value a task for a reason other than the Imbued Heart, the priority of the task can be changed in the advanced settings for that monster.  If you disagree with the kph or travel time values for a monster, they can be adjusted.  If making changes to high priority tasks such as Araxytes and Smoke Devils, it's recommended to adjust the time to obtain an imbued heart to compensate.  This value is used when suggesting which type of bracelet to use for a task.
